# 分析股票趋势

趋势分析基于已完成的常规时段前复权日线，输出未来5–20个交易日的条件判断。桌面输入股票后点击「分析走势」即可，无需 MCP 或外部 AI Key。

## 1. 获取研究结果

macOS 从仓库根目录执行：

```sh
mkdir -p artifacts/trend
apps/python/.venv/bin/python -m moopython.research_cli trend AVGO \
  --output artifacts/trend/avgo.json
```

Windows：

```powershell
New-Item -ItemType Directory -Force artifacts/trend
& .\apps\python\.venv\Scripts\python.exe -X utf8 -m moopython.research_cli trend AVGO --output artifacts/trend/avgo.json
```

该入口不会自动创建输出父目录。运行成功后读取 `trend`，其中 `outlook` 是独立规则生成的文字判断。根目录启动器没有 `trend` 子命令。

## 2. 检查数据是否适用

确认股票、采集时间和 `trend.as_of`。盘中只能使用上一已完成交易日；采集按交易日历处理假日、半日市，并在收盘后留5分钟。指标计算至少需要205根有效日线；缺失或过期数据应保留错误。

MCP 的 `get_daily_bars` 只返回日线与元数据，不直接给趋势结论。通过 MCP 获取后，分析仍应复用独立 `put_rules.py` 的 `trend()` 和 `describe_trend()`；Python 组合接口见[架构参考](../reference/architecture.md)。

## 3. 用证据解释判断

- 位置与方向：收盘价相对 MA20/50/200，MA50及短期均线的斜率。
- 动量：RSI14、MACD(12,26,9)柱及变化。
- 价位：此前20/60日低点、近期高低点结构、ATR14。
- 量：当日成交量相对前20日均量。

报告说明哪些指标支持当前判断、哪些相互矛盾，再给出关键价位和改判条件。例如价格重新站上对应均线且动量改善，可以作为重新审查的条件；超卖本身不证明止跌。

默认五项趋势参考与计算初始化见[独立规则说明](../../modules/put-screener/README.md)。规则未通过项数也参与 Put 风险评分，但不是下跌概率。关闭趋势 Filter 只取消硬拦截，风险证据和趋势描述继续保留。

历史 `cutoff` 只限制日线可用时点，不能还原当时的全部财报、公告或复权版本，因此不能直接当成历史策略回测。

## 4. 独立的价格位置与择时信号

桌面点击 Watchlist 股票后，在「分析 → 技术面依据」中显示价格信号、可见买卖盘和走势。单股和 Watchlist 的 Put / 趋势研究都会附带 `price_signals`，按股票代码组织，导出时保留。价格信号复用已完成日线；个股详情另读取该股报价与盘口。历史数据未通过原有验证时返回 `unavailable`，不推测支撑价；日线不足205根时显示原因，但仍可查看报价及有权限的盘口。

首页和左侧 Watchlist 只显示股票名、股价和涨跌；日线支撑阻力及完整价格区间、转折次数、参考价格只在点开股票后的详情页显示。最近的下方潜在支撑用绿色卡片、上方潜在阻力用红色卡片突出；没有已确认区间时不填入推测价。每次有效的单股计算会把价位和依据保存到 SQLite，按股票、日线日期、报价时间、算法版本保留历史；再次打开会更新当前计算，计算失败时可查看明确标记为历史的上次结果。这里的价位只用于浏览历史区域，不构成买入信号。

个股详情按需订阅并请求 OpenD 买卖各最多 60 档，实际返回档数随行情权限和数据而变。盘口主图的自动模式以所选时段参考价为边界，在下方 **30%** 和上方 **30%** 各分成 6 个连续的价格桶，每桶恰好是参考价的 **5%**。例如参考价 $1,000 时，下方为 $950–$1,000、$900–$950，直到 $700–$750；上方为 $1,000–$1,050，直到 $1,250–$1,300。空桶也显示为 0 股。用户可以改选固定美元桶宽，直接重算已返回的档位，不重新请求行情。30% 暂定值位于 `BOOK_BUCKET_RANGE_FRACTION`；低于下界与不低于上界的档位分别合并成一个外侧桶，不丢弃股数。参考价不可用时使用基于返回价位的美元桶宽，且不采用外侧合并。顶部突出详细范围内买卖两侧**挂单股数最多的价格桶**及股数、档数、参考金额；范围外大挂单仍在下方合并桶中可见，不占顶部的“最多”位置。随后显示金额合计、金额占比、买／卖比值和各桶的横向股数图；原有的相邻价位合并区间及最近区间显示在后面。比例按本次返回的**所有**可见档位逐档计算：买盘金额为买价 × 买盘股数之和，卖盘金额为卖价 × 卖盘股数之和；买／卖比值为前者除以后者，一侧没有可见金额时不计算比例。柱长和主数字是**股数**，不是订单笔数或美元金额；旁边的参考金额按桶或区间内每档挂单价乘以对应股数后求和，不是实际成交额。统计只涵盖当前行情源返回的可见档位，不代表全市场委托总量。显示采集时间；服务器时间缺失时明确说明无法核对盘口更新时间。挂单可撤销，也不包含隐藏流动性，不能从当前挂单量推出已成交买卖盘或支撑一定有效。日线数据已验证但暂无下方支撑区时，详情说明是没有已确认的下方转折区，并不称为 SQLite 数据不足。

盘口区间的距离按快照更新时间所在的纽约交易时段选择参考价：常规时段用 `last_price`，盘前、盘后、夜盘分别在可用时用 `pre_price`、`after_price`、`overnight_price`。详情同时标出常规时段 `last_price` 和所选时段参考价；例如盘后买盘可以高于当天常规时段最后成交价。盘后价不替换日线支撑阻力计算使用的常规时段参考价。盘口与快照仍是独立接口；若盘口服务器时间缺失，不能保证两者完全同步。

个股详情还把同一批通过验证的前复权日线汇总为周线和月线，在日线价位下方显示三个周期各自最近的支撑、阻力和数据截至日期。周线取最近52根、月线取最近18根已结束周期；不足15根时只说明数据不足。最后一个周期必须已结束，且最后一根日线落在该周期末尾两天内，才会参与计算，遇到节假日可能保守地延后显示。三个周期的区间相交时仅标记「重叠」，不推断成功率或自动修改提醒条件。周/月价位与其依据一同保存在个股 `price_signals` 历史记录内；普通 Put 排名不使用这些字段。

实现独立在 [`price_signals.py`](../../apps/python/moopython/price_signals.py)，版本与参数随结果返回。当前只提供历史转折证据，不参与现有 Filter、收益分、风险分、综合分和排名；`ranking_effect` 固定为 `none`。以后引入系数应另行确认，并保留可对比的旧排序结果。

初版使用最近120根已验证日线：左右各2根确认转折高低点，最后2根不作为已确认转折；同侧相近价位按容差聚类，容差为 `max(0.5 × ATR14, 参考价格 × 0.5%)`，聚类价格跨度不超过2倍容差，每个区域再向外扩展一个容差。同一区域的独立转折至少间隔5根日线，保留日期和确认日期；单次转折明确标为依据有限，不称为强支撑。显示最近3个潜在支撑 / 阻力区及距区域边缘的百分比、ATR距离。

位置提示条件也在同一文件：距阻力不超过1 ATR且不靠近支撑，或阻力距离小于支撑距离的一半且支撑较远时，提示等待更好的位置；价格低于MA20且MACD柱为负并继续恶化时提示等待企稳；靠近支撑仍要求观察承接。以上是未回测的描述性条件，不是开仓指令或胜率。区域边缘距离不等于 Put 的盈亏比。

Put 使用原始输入中的标的快照价格并保留时间；同股参考报价不一致时信号不可用。只查趋势时使用已完成日线收盘，并明确日期。历史转折不是当前挂单、历史成交按价分布或持仓成本；盘口承接 / 买卖比例、做市商 Gamma 均保持「未验证」。当前没有自动交易；买点提醒另存 `buy_alerts` 表，不改变 Put 排名。

## 5. 买点条件提醒与买入计划

在个股详情的「技术面依据」输入计划投入美元金额，点击「计算分批计划」。程序取当前价下最近的已确认支撑区，按区间上沿、中点、下四分位给出 40% / 30% / 30% 的假设分批价格与整股数量；后两批仅用于回踩且支撑仍有效的情景。支撑下沿作为失效参考价，显示全部三批成交后跌至该价的账面损失、未使用资金，以及到最近上方阻力下沿的账面空间。金额和价格不代表订单或保证成交；费用、滑点和跳空未计入，跌破下沿可能损失更多。没有已确认下方支撑时不自动编造买点。

可选填「风险预算 $」；0 表示不限。计划器先按投入金额计算整股批次，再按跌至支撑下沿的估算账面损失同比缩小各批股数，确保该估算不超过风险预算，并显示原估算与调整后估算。预算不是止损委托，也不能限制跳空、滑点或实际亏损。

点击「开启买点提醒」会把当时的支撑区与日线日期冻结在 SQLite。若初始报价已在支撑区，下一笔有更新时间的报价站上区间上沿，才将状态标为「条件已出现」；若初始报价在区间上方，须先观察到它进入区间，再等后续新报价站回上沿。同一笔或更早的报价不会推进两次状态。价格低于区间下沿则标为「条件失效」。终态停止轮询，重新开启会以当前信号重置；也可手动暂停。

「确认方式」可选默认的后续报价，或「次交易日收盘站回上沿」。后一方式先用新报价记录进入支撑区的时间，再等待**之后交易日**的已完成日线收盘高于冻结区间上沿；进入当天的收盘、重复或更早日线都不会确认。后续收盘若低于下沿则失效；报价先跌破下沿也会失效。此方式依赖 OpenD 的完整日线可用，详情页和后台轮询共享同一 SQLite 状态。

应用开启期间每 60 秒通过 OpenD 检查已开启提醒的股票，并在状态变为确认或失效时弹窗。应用关闭、OpenD 不可用、报价未更新或两次轮询之间发生的价格变化都无法保证捕获；这不是交易指令，也不会下单。提醒使用标的快照价格，支撑区来自已完成日线，均不代表市场一定承接。
