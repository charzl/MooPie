# 分析股票趋势

趋势分析基于已完成的常规时段前复权日线，输出未来5–20个交易日的条件判断。桌面输入股票后点击「分析走势」即可，无需 MCP 或外部 AI Key。

## 1. 获取研究结果

macOS 从仓库根目录执行：

```sh
mkdir -p artifacts/trend
apps/python/.venv/bin/python -m moopython.research_cli trend AVGO \
  --output artifacts/trend/avgo.json
```

Windows：

```powershell
New-Item -ItemType Directory -Force artifacts/trend
& .\apps\python\.venv\Scripts\python.exe -X utf8 -m moopython.research_cli trend AVGO --output artifacts/trend/avgo.json
```

该入口不会自动创建输出父目录。运行成功后读取 `trend`，其中 `outlook` 是独立规则生成的文字判断。根目录启动器没有 `trend` 子命令。

## 2. 检查数据是否适用

确认股票、采集时间和 `trend.as_of`。盘中只能使用上一已完成交易日；采集按交易日历处理假日、半日市，并在收盘后留5分钟。指标计算至少需要205根有效日线；缺失或过期数据应保留错误。

MCP 的 `get_daily_bars` 只返回日线与元数据，不直接给趋势结论。通过 MCP 获取后，分析仍应复用独立 `put_rules.py` 的 `trend()` 和 `describe_trend()`；Python 组合接口见[架构参考](../reference/architecture.md)。

## 3. 用证据解释判断

- 位置与方向：收盘价相对 MA20/50/200，MA50及短期均线的斜率。
- 动量：RSI14、MACD(12,26,9)柱及变化。
- 价位：此前20/60日低点、近期高低点结构、ATR14。
- 量：当日成交量相对前20日均量。

报告说明哪些指标支持当前判断、哪些相互矛盾，再给出关键价位和改判条件。例如价格重新站上对应均线且动量改善，可以作为重新审查的条件；超卖本身不证明止跌。

默认五项趋势参考与计算初始化见[独立规则说明](../../modules/put-screener/README.md)。规则未通过项数也参与 Put 风险评分，但不是下跌概率。关闭趋势 Filter 只取消硬拦截，风险证据和趋势描述继续保留。

历史 `cutoff` 只限制日线可用时点，不能还原当时的全部财报、公告或复权版本，因此不能直接当成历史策略回测。

## 4. 独立的价格位置与择时信号

桌面点击 Watchlist 股票后，在「分析 → 技术面依据」中显示价格信号、可见买卖盘和走势。单股和 Watchlist 的 Put / 趋势研究都会附带 `price_signals`，按股票代码组织，导出时保留。价格信号复用已完成日线；个股详情另读取该股报价与盘口。历史数据未通过原有验证时返回 `unavailable`，不推测支撑价；日线不足205根时显示原因，但仍可查看报价及有权限的盘口。

首页和左侧 Watchlist 只显示股票名、股价和涨跌；日线支撑阻力及完整价格区间、转折次数、参考价格只在点开股票后的详情页显示。每次有效的单股计算会把价位和依据保存到 SQLite，按股票、日线日期、报价时间、算法版本保留历史；再次打开会更新当前计算，计算失败时可查看明确标记为历史的上次结果。这里的价位只用于浏览历史区域，不构成买入信号。

个股详情按需订阅并读取 OpenD 前十档买卖盘，分别列出可见挂单量最大的三个价位和全部档位。显示采集时间及买卖盘服务器时间；服务器时间缺失时明确说明无法核对盘口更新时间。挂单可撤销，也不包含隐藏流动性，不能从当前挂单量推出已成交买卖盘或支撑一定有效。

实现独立在 [`price_signals.py`](../../apps/python/moopython/price_signals.py)，版本与参数随结果返回。当前只提供历史转折证据，不参与现有 Filter、收益分、风险分、综合分和排名；`ranking_effect` 固定为 `none`。以后引入系数应另行确认，并保留可对比的旧排序结果。

初版使用最近120根已验证日线：左右各2根确认转折高低点，最后2根不作为已确认转折；同侧相近价位按容差聚类，容差为 `max(0.5 × ATR14, 参考价格 × 0.5%)`，聚类价格跨度不超过2倍容差，每个区域再向外扩展一个容差。同一区域的独立转折至少间隔5根日线，保留日期和确认日期；单次转折明确标为依据有限，不称为强支撑。显示最近3个潜在支撑 / 阻力区及距区域边缘的百分比、ATR距离。

位置提示条件也在同一文件：距阻力不超过1 ATR且不靠近支撑，或阻力距离小于支撑距离的一半且支撑较远时，提示等待更好的位置；价格低于MA20且MACD柱为负并继续恶化时提示等待企稳；靠近支撑仍要求观察承接。以上是未回测的描述性条件，不是开仓指令或胜率。区域边缘距离不等于 Put 的盈亏比。

Put 使用原始输入中的标的快照价格并保留时间；同股参考报价不一致时信号不可用。只查趋势时使用已完成日线收盘，并明确日期。历史转折不是当前挂单、历史成交按价分布或持仓成本；盘口承接 / 买卖比例、做市商 Gamma 均保持「未验证」。当前没有新盘口订阅、自动交易或额外数据库表。
