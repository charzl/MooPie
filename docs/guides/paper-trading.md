# 股票策略模拟盘

在桌面顶层「模拟盘」创建实验，与「分析」并列。比较三个股票策略、股票池买入持有及 QQQ / SPY 基准。策略依据见[研究](../research/stock-strategies.md)，分层和验证要求见[实施计划](../plans/paper-trading.md)。现有卖 Put 排序与评分不变；当前模拟器执行股票策略，不会把 Put 排名直接转成股票买单。

## 开始前向观察

1. 保持本机 OpenD 已登录，准备好 Watchlist。
2. 打开「模拟盘」，点「新建实验」，设置客户数（6–100，包含两个ETF基准）、默认起始资金（每人 **$500,000**）和每只股票投入。「单独设置资金…」可逐个修改客户本金；默认固定资金，也可明确选择自动追加。点击「创建前向模拟」。股票池字段留空使用名单，也可明确输入 `AVGO,NVDA,AAPL,PLTR`。
3. 创建时保存股票池、每个客户本金、资金模式、策略参数和实现哈希。默认6个客户依次运行200日趋势、12–1个月动量、趋势中短期反转、股票池等额买入持有、QQQ买入持有、SPY买入持有。更多客户重复这六个策略；本金、参数和输入均相同时结果一致。QQQ跟踪纳斯达克100，SPY作为标普500大盘基准；它们自动采集，不加入或改变Watchlist。
4. 点「更新模拟盘」按最近完成日线推进。桌面不再每5分钟轮询；打开或切换页面只读账本。未来每日收盘调度可调用相同 `paper update ID`，当前没有配置 GitHub CI 定时运行或云端数据源。

每只股票都需要至少253个已完成常规交易日日线、相同交易日日历及公司行动数据。新上市股票、缺失历史或不支持的公司行动会阻止整个实验；错误指出股票及原因，程序不会自动删掉成员。可明确指定满足要求的股票池，也可以等历史足够。创建后修改 Watchlist 不影响已有实验。

收盘后产生信号，后续常规交易日开盘模拟成交，并计入每边5基点滑点、1基点费用；CLI可改这些假设。创建当天不会把已经过去的开盘补成成交。周末创建时先显示待执行决策和零成交。

这不是后台系统服务。窗口关闭、休眠、OpenD断线会中断更新；下一次更新可以补记已事先记录订单的成交与估值，但漏过的新决策会列出来，不伪装成当时已经运行。要连续观察，可让桌面程序及OpenD保持运行，或使用下面的CLI循环；未安装系统定时任务。

## CLI

```sh
./moomoo paper strategies
./moomoo paper create --name "Watchlist forward" --clients 6 --initial-capital 500000 --notional 10000
# 明确指定股票池，不修改 Watchlist：
./moomoo paper create --name "Four-stock forward" --symbols AVGO NVDA AAPL PLTR
./moomoo paper list
./moomoo paper update 1
./moomoo paper report 1
./moomoo paper watch 1 --interval 300
```

示例中的 `1` 替换成创建返回的实验ID。Windows 用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\moomoo.ps1 paper ...`，参数相同。安装后的命令是 `moomoo-paper`。

`--initial-capital` 为每个客户的默认起始美元本金，默认500000。通过 `--client-capitals capitals.json` 覆盖个别账户，文件内容例如 `{"client-001":250000,"client-005":750000}`；未列出的客户使用默认值，未知客户或非正数金额拒绝创建。每个账户独立拥有本金，资金不在客户之间共享。这些是实验业务配置，保存在SQLite，不随语言、主题设置改变；创建后修改表单只影响新实验。

`--funding-mode fixed` 为默认值：不借款、不自动追加现金；现金不足时，新买单等额分配剩余现金，并先预留费用，小数股不足最小精度则跳过。`auto_deposit` 显式启用原来的无限现金补资模式，新增资金单独记账。历史v1.0/v1.1实验仍保留原模式。

`create` / `update` / `watch` 主动增量更新：复用最近完成日线，缺失或过期才连接 OpenD；`--refresh` 强制采集。整个名单先通过证券预检查。`list` / `report` 只读本地数据库。`watch` 间隔60–86400秒，临时数据错误会输出错误并在下个间隔重试，Ctrl+C停止。

命令结果是JSON，可加 `--output PATH`，父目录需预先创建；SDK日志走stderr。`--input PATH` 使用专用 `paper_inputs` 原始JSON离线重现，不能把普通Put报告或QFQ日线当作模拟成交输入，也不能与 `--refresh` 同用。运行错误退出1、参数错误退出2。只使用行情接口，虚拟成交由本地账本记录。

## 单独运行历史回测

```sh
./moomoo paper backtest --name "Historical demonstration" \
  --symbols AVGO NVDA AAPL PLTR --start 2026-07-16 --end 2026-10-16
```

历史开始日期之前还需253个交易日用于热身，抓取窗口当前为550个自然日；起点过早会明确报错。`--end` 可省略，表示输入最新完成日。历史实验创建后固定，不能用 `update` 修改区间；创建新实验比较另一个窗口。当前名单用于历史重放有选择 / 生存偏差，模拟成交价不代表真实交易可成交。

## 怎么比较

表格显示各客户起始资金、净收益率、最大回撤、净损益、当前持仓比例、成交数、换手率，以及相对SPY的收益差。客户详情和JSON还保留相对QQQ、SPY、股票池买入持有的收益差（百分点）。这不是经风险调整的Alpha。换手率定义为累计双边买卖成交额 / 平均每日净资产，包含最初建仓，不是年化基金换手率。不同策略实际持仓数量不同，所以现金比例和风险暴露也要一起看。

QQQ和SPY账户默认与其他账户起始现金相同，也可逐个设置，在相同的下一常规交易日开盘各自买入一只ETF，目标投入为完整起始参考资金，而非一份单股预算；固定资金模式会预留费用，自动追加模式则单独记录补资，之后持有并计入分红、拆合股和收盘估值。分红进入现金，不自动再投资，因此并非指数总回报序列的完全复制。两个ETF的历史和公司行动缺失会阻止新实验，不自动省略基准。策略只从冻结的股票池选股，QQQ/SPY不会因额外采集而进入候选池。ETF市场价格已经反映基金内部费用，不再次另扣管理费。方法来源见[研究](../research/stock-strategies.md)。

v1.2默认每个客户50万美元、固定资金。起始本金和单股投入是独立参数：默认单股投入仍为1万美元，因此股票策略可能保留大量现金；QQQ/SPY投入各自完整本金，比较收益时也应查看持仓比例。若要相近的投入比例，应相应调整单股投入。“自动追加资金”模式明确记录现金不足时的额外注资。每股最多一份目标投入，不无限堆仓。净损益=NAV−累计注资，时间加权收益排除外部资金流，最大回撤基于同一日收盘净值曲线，不包含日内回撤。小数股保留6位，忽略现金利息、税费、预提税；现金分红在除息日应计，拆合股调整股数。未支持的送股、配股、分拆等行动阻止推进。

1、3、6个月按实验开始日起算日历月，使用到期节点当日或之后第一个已观察交易日。未到日期显示等待，不将不足6个月的记录标成6个月业绩。历史回测与前向记录分别标注，几个月、几只股票的结果不能证明长期优劣。

选择客户可查看最新指标、目标持仓、退出参考及最近20笔成交；JSON报告还保留完整历史、持仓、已实现 / 未实现损益、费用、注资和限制说明。

## 保存与升级

SQLite v5新增 `paper_experiments`、`paper_clients`、`paper_inputs`、`paper_fills`、`paper_valuations` 五张表，旧行情、证券资料、别名、Watchlist和设置保持。原始输入zlib压缩并校验SHA256；每日估值保留决策证据，成交记录信号日期和生成时间。更新在单一事务中完成，并检测并发版本，重复更新不重复成交。

模拟账本和审计输入不参加行情快照保留期清理。备份完整SQLite可长期保存，实际行情和数据库不提交Git。策略代码或引擎实现变化后，旧实验仍可读报告，但更新会要求新建实验，避免混合算法版本；不要删除原实验冒充连续业绩。v1.1新增QQQ/SPY，旧v1.0实验不倒填两个基准，相关收益差显示空值；创建新版本实验开始同日起点的比较。

v1.2新增每客户起始本金及资金模式，默认500000美元、fixed。实际金额同时保存在实验配置、客户状态与已有paper_clients.initial_capital列，无需新增表或迁移旧账本；旧实验金额保持原样。
