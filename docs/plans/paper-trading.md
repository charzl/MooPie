# 模拟盘实施计划

依据：[策略研究与原始来源](../research/stock-strategies.md)。用户要求先研究、再规划、再实现；语言 / 外观设置先完成，现有 Put 排序保持原样。

## 实验范围

股票池默认取创建时 SQLite Watchlist，冻结到实验配置，之后增删 Watchlist 不改变已有实验。模拟普通美股股票买卖，不含期权卖 Put、借券或真实下单。v1.1默认6个虚拟客户：trend_200d、momentum_12_1、reversal_5d、buy_hold、buy_qqq、buy_spy；N为6–100，每只股票目标投入金额可配置。QQQ/SPY自动附加到行情采集池，策略选股池保持原样；两个ETF基准使用相同的完整起始参考资金。相同策略、参数、输入的账户应得到相同结果，不用随机数制造不同业绩。

每个账户起始参考现金为“每股目标投入 × 股票数”，这是统一收益分母，不是资金上限。现金不足时自动补资并独立记账。单股最多一个多头仓位，不连续无限加仓。默认单股目标投入 $10,000，允许虚拟小数股；费用和滑点可配置，默认每边5基点滑点和1基点佣金，现金利息、税费和预提税不计。它们是实验假设，不代表券商收费或真实可成交价格。

## 分层与交付顺序

1. `paper_strategies.py`：纯策略与版本化参数，读取历史切片，输出目标股票、指标证据、入场参考和退出条件；不读数据库、不调用 SDK。
2. `paper_engine.py`：时间顺序、开盘成交、公司行动、持仓、费用、现金补资及收益计算。历史重放和真实前向记录分别标识；不倒填前向决策。
3. `paper_store.py` 与独立 SQL 迁移：实验、客户状态、原始输入、成交、每日估值。事务防重复更新，输入压缩和校验；账本不参加行情保留期清理。
4. 抓取层增加专用模拟盘行情输入：未复权完成日线及复权事件，经过原有缓存路由。预检查全部股票身份；任一成员缺失不推进整组实验，避免不同策略使用不同样本。
5. `paper_cli.py`：列策略、创建前向实验、更新、历史重放、报告及前台定时运行；Windows / macOS 启动器和打包入口都支持。
6. 原生桌面「模拟盘」页签：创建、选择和更新实验，查看客户比较与1/3/6个月状态；可在程序运行期间定时更新。语言和主题复用桌面设置，不建立网页。

## 时间与收益口径

每个交易日先处理公司行动，随后执行已在此前记录的目标仓位，再按收盘估值，最后生成下次交易决策。前向模式的信号生成时间必须早于成交日开盘。程序停机后可给已有预先记录的虚拟订单补记其历史成交和估值，但不能声称停机期间的新决策事先已经产生；只在最新完成日生成新的前向决策，报告漏过的决策日。

费用进入净损益。自动补资发生在开盘成交前：把“前收盘到本次开盘”的收益与“注资后开盘到收盘”的收益分开计算并链接，得到时间加权净值，注资不被算成盈利。最大回撤使用这条排除外部现金流后的净值序列。账面净损益为 NAV 减累计注资；交易胜率只统计已平仓回合，不能代替策略收益。

创建日期后的1、3、6个日历月是观察节点；报告同时给最近完成交易日和节点状态。节点数据不足或时间未到时明确 pending。历史回放不自动成为前向实验结果，报告保留当前名单历史选择偏差和模拟成交限制。

## 验证与验收

- 以有确定答案的合成路径验证费用、买卖、补资、分红、拆股、无未来函数、停机恢复、节点判断和更新幂等性。
- 验证 SQLite 旧库迁移完整保留行情、证券目录、Watchlist；输入与账本在行情清理后仍可审计。
- 同一输入与配置重复运行得到一致账本；复制账户只复制结果，不产生统计独立性。
- 实际读取当前股票池，创建前向账户并显示等待后续交易日，另做明确标记的历史演示；不编造1/3/6个月前向收益。
- 原有 Put 报告、排序、分数保持一致；必要单元测试、界面测试和 wheel 检查通过。开发期间不自动 push / 触发 CI。

## v1.1：QQQ与大盘基准

默认6个账户，新增QQQ与SPY独立买入持有。两个ETF行情自动附加、缓存复用，策略池保持冻结；每个ETF账户投入与其他账户相同的完整起始参考资金，保留费用、滑点、分红和公司行动。表格相对SPY，详情 / JSON同时保留相对QQQ及股票池的收益差。旧实验保留原版本，不倒填新增基准，新建前向与历史实验验证。

本地150项单元测试、43项界面测试通过；包含ETF数据缺失阻止推进、满额建仓、选股隔离、收益差及同参数复制一致性。新增盘后缺失行情自动采集测试：已缓存成员不重抓，全未缓存批次单次采集，失败显示原因；真实新股票完成首次抓取和第二次读库验证。MCP协议与独立wheel检查通过，未推送或触发远程CI。

## v1.2：独立本金

每客户默认500000美元，可逐个覆盖，QQQ/SPY也独立配置。本金与每股目标投入分开，默认fixed资金模式，缩单并预留费用；auto_deposit显式选择后才自动追加。配置冻结于实验，旧账本不改本金；界面、CLI、SQLite保持一致，收益比较同时显示本金与持仓比例。
